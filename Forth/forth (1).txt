Факториал:
: fact recursive 
  dup 1 > if 
    dup 1- recurse * 
  else 
    drop 1 
  then 
;

Числа Фибоначчи:
: fib recursive 
dup 2 < if 
    drop 1 
  else 
    dup 1- recurse 
    swap 2- recurse + 
  then 
;

Корни для квадратного уравнения:
: quadratic 
  \ Ввод: a b c (на стеке)
  >r >r >r \ Перемещаем a, b, c в return stack
  r@ r@ f* r> frot fover f* 4e f* f- \ Дискриминант (b^2 - 4ac)
  0e f< if 
    0 . \ Нет корней
  else 
    fdup 0e fequal if 
      r> fnegate 2e f/ f. \ Один корень
      1 . 
    else 
      fsqrt r> fnegate frot fover f- 2e f/ f. \ Первый корень
      r> fnegate frot fover f+ 2e f/ f. \ Второй корень
      2 . 
    then 
  then 
;

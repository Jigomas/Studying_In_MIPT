# Реализация AVL-дерева

Оптимизированная реализация сбалансированного бинарного дерева поиска на C с автоматической балансировкой.

## Основные возможности

- Автобалансировка Поддержка свойства AVL (разница высот ≤ 1)
- Эффективная память Оптимизация переиспользования узлов
- Базовые операции
  - Вставка с балансировкой
  - Удаление с балансировкой
  - Поиск элементов
  - Обход дерева
- 4 типа вращений
  - Левое-Левое (LL)
  - Левое-Правое (LR)
  - Правое-Правое (RR) 
  - Правое-Левое (RL)

## Структура проекта

### Узел дерева
```c
typedef struct Node {
    void* data;         // Данные
    int height;         // Высота поддерева
    struct Node* left;  // Левый потомок
    struct Node* right; // Правый потомок
} Node;
```
